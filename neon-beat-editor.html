음악 선택 (브라우저)

브라우저에 저장된 곡 목록입니다. 선택하면 바로 사용합니다.
처음이거나 새 곡이면 아래 기기에서 추가로 한 번만 넣으면 됩니다.

에디터 도움말

기본 조작

  • 탭 — 클릭으로 단타 배치/제거
  • 홀드 — 드래그로 길이 지정
  • 지우개 · 우클릭 — 노트 삭제
  • 스냅 — 1/4 · 1/8 · 1/16 박 단위로 붙임
  • 스크롤 — 휠, ▲▼, Space+드래그, 두 손가락
  • 실행취소 — 버튼 또는 Ctrl+Z

BPM · 길이 · 속도

  • BPM — 곡 템포. 노트 시간 계산에 사용
  • 박(마디) — 차트 전체 길이 (1마디 = 4박)
  • 속도 — 기본 노트 낙하 배율 (툴바 −/+)
  • 속도 도구 — 타임라인 클릭으로 중간 배속 트리거 배치 (노란 점선)
  • 트리거 배율 = 배치 순간 툴바 속도. 같은 위치 재클릭 시 갱신/삭제
  • 테스트·본 게임에서 해당 박부터 낙하 속도 변경

음악 (Song ID)

  • 음악 선택 — 브라우저에 저장된 곡 목록
  • 처음 곡은 기기에서 추가로 한 번만 넣으면 됨
  • 채보에는 Song ID·이름·길이만 저장 (용량 작음)
  • 실제 음원은 브라우저 IndexedDB에 보관
  • file://로 파일을 따로 열면 저장소가 갈라질 수 있음 → 같은 브라우저·「게임으로」 권장

저장 · 공유 · 게임

  • 저장 — 이 브라우저에 채보 저장
  • 게임으로 — 채보를 넘기며 본 게임 실행 (해시로 전달)
  • 내보내기 — 압축 코드 / JSON 복사
  • 가져오기 — 코드 붙여넣기
  • 압축 예: 1.30-2-0@0,1@1:2|176|16

규칙 (불가능한 패턴)

  • 같은 레인에서 노트·홀드가 시간상 겹치면 배치 불가
  • 홀드 몸통 위에 다른 노트 올리기 불가
  • 끝점만 맞닿는 연속 배치는 허용

테스트 플레이

  • 키 D F J K 또는 화면 터치
  • 연결된 음악이 있으면 준비 시간 후 재생
  • 판정 창·홀드/슬라이드 점수 공식은 본 게임과 동일
